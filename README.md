# سَبْر (Sabr) — منصة التحقق من صحة الأدلة الرقمية عبر بصمة الشبكة الكهربائية

نموذج أولي شغّال بالكامل: معالجة إشارات حقيقية (Bandpass Filter + STFT +
استيفاء تقاطعي) لاستخراج بصمة تردد الشبكة الكهربائية (ENF)، مع قاعدة
بيانات محلية (SQLite) — **بدون أي حساب خارجي أو مفاتيح API**.

## الملفات
- `enf_core.py` — استخراج ومقارنة بصمة ENF (المحرك العلمي)
- `db.py` — طبقة قاعدة البيانات (SQLite محلي، ملف واحد داخل المشروع)
- `app.py` — واجهة Streamlit
- `requirements.txt` / `packages.txt` — المكتبات المطلوبة

## النشر (خطوة واحدة فقط، بدون Secrets)

1. أنشئي مستودع GitHub عام جديد وارفعي ملفات هذا المجلد كاملة
2. ادخلي [share.streamlit.io](https://share.streamlit.io) وسجّلي بحساب GitHub
3. **New app** → اختاري المستودع → الملف الرئيسي `app.py` → **Deploy**

خلال دقيقتين رابط دائم مجاني، **جاهز للاستخدام فورًا بدون أي إعداد إضافي.**

## طريقة الاستخدام
- **الخطوة ١ بالتطبيق**: ارفعي مقطع الأرشيف المرجعي، وحدّدي تاريخ ووقت
  بداية التسجيل الفعلي، ثم احفظيه — يتراكم مع كل رفعة جديدة.
- **الخطوة ٢**: ارفعي أي فيديو أو تسجيل صوتي للتحقق منه — يقارَن تلقائيًا
  بكامل الأرشيف المتراكم، ويظهر التاريخ والساعة الحقيقيين للمطابقة، أو
  يكشف نقطة التلاعب والفترة الزمنية المفقودة بالضبط.

## ملاحظة مهمة (بدل تعقيد الإعداد)
البيانات محفوظة بملف محلي طول ما التطبيق نشِط ومُستخدم. لو التطبيق نام
لفترة طويلة جدًا أو أُعيد نشره من الصفر، قد يبدأ الأرشيف فارغًا من جديد.
**للعروض والمسابقات هذا كافٍ تمامًا** — ارفعي الأرشيف المرجعي قريبًا من
موعد العرض التقديمي (نفس اليوم أو اليوم اللي قبله)، وخلي التطبيق
مفتوحًا ومُستخدمًا خلال فترة التحضير.

## ملاحظة علمية
تم اختبار محرك الاستخراج (`enf_core.py`) فعليًا وأثبت التقاطه لفروقات
ترددية دقيقة جدًا وكشفه الصحيح لنقاط القص والدمج. هذا نموذج أولي يثبت
المبدأ العلمي، وليس نظامًا معتمدًا رسميًا للاستخدام القضائي الفعلي بعد.
