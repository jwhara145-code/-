# سَبْر (Sabr) — منصة التحقق من صحة الأدلة الرقمية عبر بصمة الشبكة الكهربائية

نموذج أولي شغّال بالكامل: معالجة إشارات حقيقية (Bandpass Filter + STFT +
استيفاء تقاطعي) لاستخراج بصمة تردد الشبكة الكهربائية (ENF)، مع **قاعدة
بيانات دائمة** (Supabase) تحفظ الأرشيف المرجعي بشكل مستمر.

## الملفات
- `enf_core.py` — استخراج ومقارنة بصمة ENF (المحرك العلمي)
- `db.py` — طبقة قاعدة البيانات الدائمة (Supabase)
- `app.py` — واجهة Streamlit
- `requirements.txt` / `packages.txt` — المكتبات المطلوبة

## الخطوة ١: إنشاء قاعدة البيانات المجانية (Supabase)

1. أنشئي حسابًا مجانيًا على [supabase.com](https://supabase.com) (بدون بطاقة ائتمان)
2. **New Project** → اختاري اسمًا وكلمة مرور لقاعدة البيانات (احفظيها) → انتظري دقيقة حتى يجهز المشروع
3. من القائمة الجانبية اذهبي لـ **SQL Editor** → **New query** والصقي:

```sql
create table enf_archive (
  id bigint generated always as identity primary key,
  captured_at timestamptz not null,
  freq_hz double precision not null,
  created_at timestamptz default now()
);

create index on enf_archive (captured_at);
```

اضغطي **Run** — هذا ينشئ الجدول الدائم الذي سيحفظ كل نقاط الأرشيف.

4. اذهبي لـ **Settings → API** وانسخي قيمتين:
   - **Project URL**
   - **anon public key**

## الخطوة ٢: النشر عبر Streamlit Community Cloud

1. أنشئي مستودع GitHub عام جديد وارفعي ملفات هذا المجلد كاملة
2. ادخلي [share.streamlit.io](https://share.streamlit.io) وسجّلي بحساب GitHub
3. **New app** → اختاري المستودع → الملف الرئيسي `app.py`
4. **قبل** الضغط على Deploy، افتحي **Advanced settings → Secrets** والصقي
   **بالضبط** بهذا الشكل — كل قيمة بسطر واحد كامل بدون كسرها لسطرين،
   وبدون أي نص إضافي غير القيمة نفسها بين علامتي التنصيص:

```toml
SUPABASE_URL = "https://xxxxxxxxxxxx.supabase.co"
SUPABASE_KEY = "sb_publishable_xxxxxxxxxxxxxxxxxxxxxxxx"
```

استبدلي القيمتين بما نسختوه فعليًا من صفحة Settings → API.

5. اضغطي **Save**، ثم **Deploy** — خلال دقيقتين يصير عندكم رابط دائم مجاني.

## طريقة الاستخدام
- **الخطوة ١ بالتطبيق**: ارفعي مقطع الأرشيف المرجعي، وحدّدي تاريخ ووقت
  بداية التسجيل الفعلي، ثم احفظيه — يتراكم بقاعدة البيانات مع كل رفعة جديدة.
- **الخطوة ٢**: ارفعي أي فيديو أو تسجيل صوتي للتحقق منه — يقارَن تلقائيًا
  بكامل الأرشيف المتراكم، ويظهر التاريخ والساعة الحقيقيين للمطابقة، أو
  يكشف نقطة التلاعب والفترة الزمنية المفقودة بالضبط.

## استكشاف الأخطاء
لو ظهرت رسالة "قاعدة البيانات غير مهيَّأة"، افتحي مربع "تفاصيل الخطأ
التقنية" أسفلها بالتطبيق نفسه — يوضح لك رسالة الخطأ الحقيقية (مثلًا:
مفتاح خاطئ، أو الجدول غير موجود بعد).

## ملاحظة علمية
تم اختبار محرك الاستخراج (`enf_core.py`) على إشارات اصطناعية دقيقة وأثبت
التقاطه لفروقات ترددية أقل من ٠.٠٣ هرتز بدقة عالية (ثقة تطابق تصل ٩٨٪)،
وكشفه الصحيح لنقاط القص والدمج. هذا نموذج أولي يثبت المبدأ العلمي، وليس
نظامًا معتمدًا رسميًا للاستخدام القضائي الفعلي بعد.
